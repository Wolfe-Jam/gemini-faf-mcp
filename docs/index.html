Get started in three steps

Works in Gemini CLI and Google Antigravity. Runs on Python through uvx.

1

Install the extension

One command adds the MCP server and the /faf commands to Gemini CLI.

2

Create your project.faf

Writes a starter file and scores it. Then ask Gemini to fill it in from your repo.

3

Check the score

See what's filled and what's missing, then take it to 100%.

Using another MCP client? Run uvx gemini-faf-mcp, or pip install gemini-faf-mcp.

Works in Google Antigravity

Antigravity reads one MCP config file, and it takes both modes. Read how it works ›

~/.gemini/config/mcp_config.json · local
{
  "mcpServers": {
    "gemini-faf": { "command": "uvx", "args": ["gemini-faf-mcp"] }
  }
}
~/.gemini/config/mcp_config.json · hosted
{
  "mcpServers": {
    "gemini-faf": { "serverUrl": "https://mcpaas.live/gemini/mcp/v1" }
  }
}

Antigravity expects serverUrl, not url or httpUrl.

Thirteen tools. You can see what each one does.

Reading tools never touch your files. Writing tools say so.

Read only
faf_readfaf_validatefaf_scorefaf_discover faf_contextfaf_stringifyfaf_modelfaf_about
Write without losing anything
faf_initfaf_autofaf_geminifaf_agents
Rewrites the file
faf_migrate

faf_init never overwrites. faf_auto fills empty slots only. faf_gemini and faf_agents update their own section of GEMINI.md and AGENTS.md and keep the rest. faf_migrate re-saves the file, so YAML comments are not kept.

100%

One score, everywhere

Always-33: every app is scored on the same 33 slots, the same number faf-cli gives. Slots that don't apply are marked slotignored, so they still count. Trophy ✪ = 100%: AI is optimized to code.

Stop re-explaining your project

.faf is read once at session start. Every prompt lands on a Gemini that already knows your project.

without FAF
You:    I'm using FastAPI with PostgreSQL,
        pytest, and…
Gemini: Got it. What's the codebase like?
You:    It's a REST API for…
        [5 minutes of re-explaining]
with FAF
You:    Add a /users/me endpoint
Gemini: [writes the code with your auth
         pattern and your test style]
